# Keyboard shortcuts

The shortcuts below cover the application shell as shipped in the foundation release.
More arrive as feature lanes land; the command palette remains the fastest way to
reach anything, whether or not it has a shortcut.

## Global

| Shortcut | Action |
| --- | --- |
| `Ctrl+Shift+F` | Open the command palette |

The palette searches every command, feature page, setting, and documentation article.
Type to filter, pick a result, and the app jumps straight to it. It works from
anywhere in the app.

## Tabs

| Shortcut | Action |
| --- | --- |
| `Ctrl+W` | Close the current tab |
| `Arrow keys` | Move between tabs in the strip |

Arrow navigation follows the strip's orientation: with the strip docked to the top or
bottom edge, Left and Right move between tabs; docked to the left or right edge, Up
and Down do. Dock position is set from the tab strip's context menu or settings.

## Tips

- The shortcuts above are active across the whole shell, not just one surface, so the
  palette and tab controls behave the same wherever you are.
- If a shortcut seems ignored, check that focus is inside the app window rather than
  on a dialog awaiting a decision.
- Everything reachable by mouse is also reachable by keyboard; nothing in the shell
  requires pointing at it.

This site documents Material Router. The app itself is not hosted here — installers live on the GitHub releases page.

Platform 平台與發佈

Windows x64, Squirrel.Windows installer, unsigned by policy, with Chrome-style updates over HTTPS.

Windows x64、Squirrel.Windows安裝程式、按政策唔簽名，更新走HTTPS。

Behaviour 行為

Releases ship a Squirrel.Windows installer targeting 64-bit Windows, produced by the repository build scripts (build.bat / build-installer.bat). Auto-updates follow the Squirrel model: the app checks an HTTPS feed, stages new versions, and installs them when you choose to restart.

Release附Squirrel.Windows安裝程式，目標64-bit Windows，由repo自己嘅建置腳本（build.bat / build-installer.bat）生產。自動更新跟Squirrel模型：app查HTTPS feed、預存新版本、等你肯重啟先裝。

Configuration 設定

The updater exposes a manual check-for-updates action and shows availability without interrupting work; installation happens only after you choose to restart. Nothing else to configure.

更新器有手動「檢查更新」掣，會顯示有冇新版本但唔打斷你做工；幾時裝由你揀重啟嗰刻決定。其他嘢毋須設定。

Failure modes 失敗模式

Unsigned installers, stated plainly: this project permanently does not code-sign. Expect the Windows SmartScreen warning on first run — choose More info, then Run anyway — and verify downloads independently against SHA-256 digests published with each release where provided.

  • Feed unreachable → checks fail quietly and retry later; the app keeps working.
  • Corrupt download → digest validation rejects it; nothing is staged.
  • Failed install → Squirrel rolls back, previous version intact.

無簽名安裝程式，講明喺先：本項目永遠唔會代碼簽名。第一次行一定遇到SmartScreen警告 —— 揀「更多資訊」再「仍要執行」—— 並且用release公佈嘅SHA-256獨立核對下載檔。

Feed連唔上 → 檢查靜靜失敗遲啲再試，app照常用得；下載壞包 → 核對數值不符就拒收，乜都唔會預存；安裝失敗 → Squirrel回滾，舊版原封不動。

Security 安全考量

Update transport is HTTPS. There is no signature chain to rely on, so independent verification of downloads is your safeguard — disclosed here rather than implied away. No signing certificate exists in this project’s toolchain, by policy.

更新傳輸行HTTPS。冇簽名鏈可信，所以獨立核對下載檔就係你嘅保障 —— 呢度講明而唔含糊帶過。按政策，本項目工具鏈入面根本不存在簽名證書。

Verification 驗證方法

The installer installs, launches and uninstalls cleanly on Windows x64; published digests match attached artifacts byte for byte; the update feed serves valid metadata and a staged update installs on restart.

喺Windows x64上安裝、啟動、解除安裝全部乾淨俐落；公佈嘅digest同附件逐位元組吻合；更新feed提供合法metadata，預存嘅更新喺重啟後順利裝上。

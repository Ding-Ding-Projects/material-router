# Material Router - Roadmap

Status legend: `[x]` shipped and verified in this repository · `[ ]` planned or owned by an open lane.
Items are never silently deleted; dropped ideas move to "Deliberately not doing" with a reason.

## Phase 0 - Foundation (shipped)

- [x] Repository scaffolding: zero runtime dependencies, dev-only toolchain, MIT license
- [x] Squirrel.Windows packaging config with signing permanently disabled and stated in output
- [x] Release workflow skeleton (no test/lint jobs by policy) with artifact safety net
- [x] One-click scripts: `build.bat`, `build-installer.bat`, `download-dependencies.bat`
- [x] Atomic JSON store (unique temp name, EPERM/EACCES/EBUSY retry, debounced saves)
- [x] Encrypted vault (safeStorage, length-prefixed records, scrypt lock hashing, obfuscation fallback warning)
- [x] IPC registry with domain allowlist (`settings`, `vault`, `server`, `providers`, `builder`, `logs`, `history`, `notify`, `dialog`, `shell`, plus added `docs`)
- [x] Loopback router server: `/v1/chat/completions`, `/v1/messages`, `/v1/models[/id]`, `/health`, CORS preflight
- [x] Bearer auth toggle, 10 MB body limit, rejecting 120 s deadlines, upstream abort on client disconnect
- [x] Bidirectional OpenAI ↔ Anthropic translation incl. streaming chunks both directions
- [x] Providers store: CRUD + routing rules (prefix/exact/catchall, deterministic priority) + TTL model cache
- [x] M3 token sheet (light+dark) and component classes (buttons, cards, fields, switches, chips, dialogs, snackbars, tooltips)
- [x] Frameless window, custom titlebar with window controls, single-instance lock
- [x] Tab strip: dock L/R/T/B, overflow scrolling, drag reorder, pinning, collapsible named groups, move-via-picker, rename, close guards, roving-tabindex keyboard, ARIA roles
- [x] Command palette (`Ctrl+Shift+F`) with fuzzy filter, rich inline controls, bounded/full view, teleport highlight
- [x] Search bars with anchored regex builder popover (flags, live matches, capture groups, 64KB sample bound, step-budgeted matcher)
- [x] Notification center: non-blocking toasts, searchable history, bulk dismiss/export, confirm-gated clear-all
- [x] Local history journal with date/action/text filters and export
- [x] Offline docs browser (bundled articles, internal links, regex-capable search) + index generator script
- [x] i18n EN / zh-HK / bilingual + per-language funny levels 1–5 + emoji-toggle gate hook + School-mode hook stub
- [x] Brand assets generated by dependency-free script (icon.png/@2x/.ico, social-preview x2 byte-identical)
- [x] Root documentation set: README, HANDOFF, AGENTS, feature index, offline article seed set

## Phase 1 - Feature lanes

- [x] Builder lane: visual API builder (compose, translate-preview, send through local router, save/load requests)
- [x] Providers lane: provider/key/routing-rule GUI on top of existing stores and vault IPC
- [x] Server lane: server controls surface, live log stream view, per-request detail
- [x] Appearance lane: per-element appearance editors, presets, export/import, tab appearance from context menu event
- [x] Delight lane: School mode implementation, element toy locks + unlock ladder, super-confirmation gate upgrade, narrator/TTS, dim-sum surprise, ADHD modes
- [x] Utility lane: local file converter suite, extended toolbox, docs browser extensions
- [x] Authenticator lane: TOTP entries, QR pairing flow, RFC 6238 vectors (verified against RFC 4226 + RFC 6238 Appendix B; QR encoder proven by decode-back with independent GF(256) syndrome check)
- [x] Site lane: GitHub Pages landing/documentation site with full feature contract parity

## Phase 2 - Hardening & platform

- [x] Plumbing lane: unique monotonic release tags, line-count table in release notes, dim-sum release asset, workflow timing evidence (pipeline merged; first live run proves it at the next push to main)
- [x] Local zero-dependency test suite (`npm test`, node:test only) covering translator round-trips + streaming both directions, store atomic writes + retry seam, providers route resolution, upstream deadline/SSE/error normalization via loopback fixture server, vault scrypt + obfuscation persistence — 88 tests green on Windows Node 24 (CI still runs no tests by policy); suite found and fixed two product bugs: vault obfuscation header mismatch made fallback secrets unreadable, JSONStore.delete reported success for absent keys
- [ ] Auto-updater: unsigned-feed check-on-start/background schedule, ready banner, restart-to-install protections
- [ ] Dependency digest manifest for downloaded binaries (versions + SHA-256, verified by fetcher)
- [ ] Accessibility audit pass across every registered surface
- [ ] Local version history for settings and user-managed records (snapshot/restore panel)

## Deliberately not doing

- Code signing, in any form, ever (project policy).
- Test or lint jobs inside GitHub Actions workflows (project policy); local checks remain the author's responsibility in the task that changes code.
